# PS2 Web — محاكي PlayStation 2 (PWA)

كل الملفات في مجلد واحد (بدون مجلدات فرعية) ليسهل رفعها من الهاتف.

## الرفع
ارفع **كل** الملفات إلى المستودع (الفرع main)، ثم Settings → Pages → Deploy from a branch → main / root.
الرابط: `https://USERNAME.github.io/REPO/`

## إذا كانت نسخة قديمة عالقة
افتح مرة واحدة: `https://USERNAME.github.io/REPO/reset.html` — يمسح الذاكرة القديمة ثم يفتح المحاكي.

## التثبيت
Chrome: القائمة ⋮ ← Install app / Add to Home screen (يظهر بعد تحميل الصفحة وتفعيل الـ Service Worker).

## أزرار اللمس
من ⚙️ Settings ← **Touch Controls**: تفعيل/إخفاء، الحجم، الشفافية، الاهتزاز. تظهر الأزرار أثناء تشغيل لعبة فقط.
الأزرار تحاكي لوحة المفاتيح؛ لتعديل المفاتيح افتح `touch.js` وغيّر الجدول `KEYS` في أعلاه.

## الأداء والألعاب الكبيرة
- الأقراص (حتى 2 جيجا وأكثر) تُقرأ على دفعات من الملف مباشرة ولا تُنسخ إلى الذاكرة؛ الحد الأقصى للكاش 128 ميجابايت.
- زر **Max Performance Preset** في الإعدادات يفعّل أسرع إعدادات (وتُحفظ تلقائيًا).
- السرعة النهائية تعتمد على قوة المعالج؛ لا يوجد Frameskip حقيقي في هذا المحاكي.
- أزرار اللمس تعمل أيضًا مع يد تحكم بلوتوث/USB.

## تشخيص
زر 🐞 أسفل يسار الصفحة يعرض الأخطاء، ورقم النسخة (v2.1) يظهر أسفل اليمين.

الألعاب غير مضمّنة؛ استخدم أقراصًا تملكها (ISO/CSO/CHD/ISZ/BIN/ELF). المحاكي: Play! (purei.org).
